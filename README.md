### 文件路徑 
```
├── backend/
│   ├── app.py   # 後端主要應用程式
│   └── firebase_config.json  # DB金鑰
|
├── static/ 
│   ├── css/
│   │   └── css files
│   ├── js/
│   │   └── js files
│   └── html/
│       └── html files
|
├── resources/
│   └── resources files
|
├── requirements.txt
└── README.md
```
---
### First : 

- Run `pip install -r requirements.txt`  in the terminal

### Second :

- 執行 app.py

### Third :

- press `Ctrl` and `click` on the url `http://192.168.X.X:5000`

![alt text](resources/image.png)

### Fourth :

- press `Ctrl + C` in terminal to quit the app
